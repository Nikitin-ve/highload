## Миграции базы данных

В проекте реализована система миграций для базы данных PostgreSQL. Миграции хранятся в виде отдельных SQL-файлов в директории `schemas/postgresql/migrations/` и применяются автоматически при запуске сервиса.

### Структура миграций

Файлы миграций должны соответствовать следующему формату именования:
```
NNN_описание_миграции.sql
```
где `NNN` - номер версии миграции (любое число, миграции применяются в порядке возрастания номеров).

Примеры миграций:
- `001_initial_schema.sql` - начальная схема с таблицей key_value_table
- `002_add_timestamp.sql` - добавление поля created_at с временем создания записи

### Система миграций

Система миграций состоит из следующих компонентов:

1. **Директория миграций** - `schemas/postgresql/migrations/` содержит все файлы миграций
2. **Таблица schema_migrations** - хранит информацию о примененных миграциях
3. **Компонент PostgresSchemaInit** - загружает и применяет миграции при запуске приложения

### Как работает компонент миграций

При запуске приложения:

1. Компонент `postgres-schema-init` создает таблицу `schema_migrations`, если она не существует
2. Сканирует директорию `schemas/postgresql/migrations/` для поиска всех файлов миграций
3. Загружает содержимое каждого файла миграции и сортирует миграции по номеру версии
4. Для каждой миграции проверяет, была ли она уже применена (запись в таблице `schema_migrations`)
5. Применяет только новые миграции, записывая информацию о них в таблицу `schema_migrations`

### Добавление новой миграции

Для добавления новой миграции:

1. Создайте новый SQL-файл в директории `schemas/postgresql/migrations/` с именем в формате `NNN_описание.sql`, где номер NNN должен быть больше номеров существующих миграций
2. Поместите в файл необходимые SQL-команды для изменения схемы базы данных
3. При следующем запуске приложения миграция будет автоматически применена

Пример создания новой миграции:

```bash
# Создание новой миграции для добавления нового индекса
echo "CREATE INDEX idx_key_value_created_at ON key_value_table(created_at);" > schemas/postgresql/migrations/003_add_created_at_index.sql
```

## Веб-интерфейс

Проект включает веб-интерфейс для удобного взаимодействия с API хранилища ключ-значение. Веб-интерфейс автоматически доступен при запуске сервиса.

### Структура веб-интерфейса

- `frontend/index.html` - основная страница веб-интерфейса
- `frontend/styles.css` - стили веб-интерфейса
- `frontend/script.js` - JavaScript-код для взаимодействия с API

### Функциональность веб-интерфейса

Веб-интерфейс предоставляет формы для выполнения следующих операций:
1. **GET** - получение значения по ключу
2. **POST** - установка значения для ключа
3. **DELETE** - удаление ключа

### Доступ к веб-интерфейсу

После запуска сервиса веб-интерфейс доступен по адресу:
```
http://localhost:8087/
```

## Преимущества системы миграций на основе файлов

- Разделение кода бизнес-логики и схемы базы данных
- Простое добавление новых миграций без изменения кода приложения
- Автоматическое применение миграций в правильном порядке
- Отслеживание версий схемы базы данных через Git
- Возможность легко восстановить базу данных с нуля, применив все миграции
